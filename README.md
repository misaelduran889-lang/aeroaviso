# AeroAviso

Alertas de vencimientos aeronáuticos (pagos y tasas, licencias, mantenimiento, operaciones, equipos encendidos y problemas reportados) con notificaciones del sistema.

- **Android:** descarga `AeroAviso.apk` desde *Releases* e instálalo. Al activar las notificaciones el teléfono pide permiso; queda en Ajustes → Aplicaciones → AeroAviso → Notificaciones. Los avisos se programan en el teléfono y llegan aunque la app esté cerrada.
- **Laptop:** abre la versión web (GitHub Pages) y activa las notificaciones; llegan al centro de notificaciones mientras la página esté abierta o minimizada.

Cada cambio en `main` vuelve a compilar el APK automáticamente.
